# Learning progress

The progress file for `methods/learning.md` (PM3). For each lesson it records only the date, the lesson number, pass or fail, the test score as a percentage, the Operator's rating and the PM/RE's rating. Worked answers, especially for account cases, stay in `pm-private\library`. This branch is public.

**Rating scale** (the same for both ratings): 0 = never heard of it; 1 = can explain it in plain words; 2 = at least 70% on the module test; 2.5 = at least 80% and computes it unaided on real data; 3 = at least 90% and can teach it back.
